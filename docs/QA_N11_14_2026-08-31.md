### F-3 (S2) 선이 원판 밑으로 파고든다 — 오너 지적 사실

`meta_tree_screen.gd:1310`:

```gdscript
var rim: float = _node_size() / 2.0 + 3.0          # 28 + 3 = 31
if from.distance_to(to) > rim * 2.5:               # 임계 77.5px
    from = from + axis * rim
    to = to - axis * rim
```

트림 임계가 **77.5px**인데 실제 인접 링크 평균이 가로 공용 **77.7px**, 연마 81.0px, 세로 연마 86.1px다. 임계선이 데이터 중앙값 위에 놓여 있어 **링크의 절반 이상이 트림을 건너뛰고 중심-중심 풀렝스로 그려진다** — 정확히 "원판 밑으로 파고드는 선".

- 최악: 가로 공용 **18개 중 14개(78%)**
- `else` 분기라 짧은 링크일수록 반드시 파고든다 — **가장 촘촘해서 가장 지저분해 보이는 구간에서만 발동**한다
