## 5. R-1 (신규, HIGH) — 연마 노드를 탭하면 탭이 통째로 날아간다

**재현** (`v6b_refine_tap.png`, 세로 540×960)

1. 수련 → **연마** 탭을 연다 (17노드 표시).
2. 아무 노드나 탭한다 (`refine_attack_damage`).
3. 화면이 **공용 탭으로 튄다.** 방금 누른 노드는 화면에 없고(`node still on canvas=false`), 플로팅 캡션도 사라진다(`caption visible=false`).

**원인** — `meta_tree_screen.gd:487 select_node()`

```gdscript
var branch: String = MetaTree.node_character(MetaTree.node(_tree, node_id))
if branch != _current_tab:
    _current_tab = branch
    _populate_tab()
```

`_on_node_pressed()`는 마지막에 `select_node()`를 부른다. 연마 노드는 데이터상 여전히 트렁크 소속이라 `node_character()`가 `""`(= `TAB_TRUNK`)를 돌려준다. 현재 탭 `"_refine"`과 다르므로 "선택이 보이도록 탭을 따라간다"는 원래 의도가 **정확히 반대로** 작동해, 탭한 노드가 안 보이는 탭으로 화면을 옮긴다.

I-3이 `_tab_nodes()`에서만 `REFINE_PREFIX`로 트렁크를 갈랐고, `select_node()`의 탭 판정은 그대로 `node_character()`에 남아 생긴 누락이다.

**영향** — 연마 탭의 17개 노드는 **선택도 구매도 불가능하다.** 탭할 때마다 공용 탭으로 튕겨 나온다. I-3이 옮겨 놓은 노드 전부가 사실상 도달 불가.

**측정 재현율** 6/6 조합(3해상도 × 2로케일) 전건. `_v4_caption`의 프로브에서도 동일하게 12회 재현.

**수리 방향(제안)** — `select_node()`가 `_tab_nodes()`와 같은 규칙으로 탭을 고르게 한다:

```gdscript
var branch: String = MetaTree.node_character(MetaTree.node(_tree, node_id))
if branch == TAB_TRUNK and node_id.begins_with(REFINE_PREFIX):
    branch = TAB_REFINE
```

탭 소속 판정이 두 곳에 흩어져 있는 것이 근인이므로, `_tab_for(node_id)` 하나로 모으고 `_tab_nodes()`와 `select_node()` 양쪽이 그것만 보게 하는 편이 재발을 막는다.
