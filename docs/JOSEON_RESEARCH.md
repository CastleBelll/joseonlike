# 조선 괴이·직업·장소 리서치 (2026-08-19)

전략 감사(2026-08-19)의 결론 — "코어 루프는 돌아간다, 부족한 건 콘텐츠 물량" —
에 대한 소재 조사. 오너 지시: **조선 사람들이 잘 모르는 괴이**, **조선에 어울리는
직업**, 지역 특색.

이 문서는 **소재 카탈로그이지 구현 계약이 아니다.** 실제 수치·티어·밸런스는
`data/`와 [TASKS.md](../TASKS.md)의 해당 피처가 정한다. 트레이트 제안은 전부
설계 판단이며 문헌 근거가 아니다.

  해당 일자 원문을 확인하고 나서 데이터에 넣는다.

### 근거가 약한 항목 (쓰려면 각색임을 인정하고 쓴다)

- **그슨대·어둑시니**: 이름과 "어둠에서 커진다"는 핵심은 방언·구전 기록으로
  실재. 그러나 "소년 모습으로 유인" "가재를 좋아함" "올려다보면 커진다"의
  구체 서술은 **현대 각색** 비중이 크다.
