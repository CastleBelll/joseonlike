# 수련 트리 재설계 계획 (N11-18)

오너 지시 (2026-08-31): *"무작정 노드 연결하기보다 제대로 글로 정리해서 노드를
연결시키는 게 낫겠다. 지금은 이미 존재하던 것들을 노드로 연결만 하고 있는 것 같은데,
제대로 업그레이드 개념으로 구성을 진행하고 노드화 시켰으면 좋겠다. 필요없는 건 빼고
필요한 게 더 있으면 추가하는 방식으로."*

이 문서는 **구현 전 합의용**이다. 승인 전에는 데이터를 건드리지 않는다.

---

## 1. 지금 트리가 틀린 지점 (측정)

노드 79개, 스탯 31종. **31종 중 24종(77%)이 2개 이상의 탭에 중복**한다.

| 스탯 | 나타나는 탭 |
|---|---|
| attack_speed · hit_invuln | 공용 · 연마 · 우치 · 석주 · 월영 (5탭 전부) |
| crit_chance · crit_damage · damage_reduction · move_speed · projectile_speed | 4탭 |
| attack_damage · max_hp · luck · magnet_radius · xp_gain | 3탭 |

즉 지금 트리는 **"배선된 스탯 31종을 탭마다 다시 뿌린 목록"** 이지 업그레이드 구조가
아니다. 플레이어 입장에서 공용의 `부적 연마`(공격력 +4%)와 연마의 `공격력 연마`
(공격력 +6%)는 **같은 것을 두 번 파는 것**이고, 탭을 옮길 이유가 없다.

부수 문제:
- **아이덴티티 없음**: 우치 탭 15노드 중 9개가 다른 탭에도 있는 스탯이다. "우치를
  키운다"가 "숫자를 또 올린다"와 구분되지 않는다.
- **구조적 업그레이드 부재**: 79노드 전부가 `stat += x` 형태다. 규칙을 바꾸는 것
  (해금·자동화·보험·경제)이 하나도 없다. 아이들러에서 오래 미는 힘은 규칙 변화에서 온다.
- **잉여**: 체감 최하위 축이 4탭에 중복한다 (`projectile_speed`).

## 2. 설계 원칙

1. **한 스탯은 한 집에만 산다.** 중복 배치 금지. 캐릭터 탭은 *그 캐릭터만의* 규칙을 판다.
2. **탭마다 다른 질문에 답한다.**
   - 공용 = "출정을 어떻게 운영할 것인가" (경제·준비·보험)
   - 연마 = "기본기를 얼마나 벼릴 것인가" (전투 스칼라)
   - 캐릭터 = "이 수행자는 무엇이 되는가" (그 캐릭터의 규칙)
3. **깊이 ≤ 4, 뿌리 ≥ 5.** 격자 웹이 세로 화면에서 담는 한계 (측정: 세로 반지름
   ~230px, 칸 70px). 이 한계를 데이터가 지킨다.
4. **티어마다 성격이 다르다.** 1티어=스칼라, 2티어=조건부 스칼라, 3티어=규칙 변경,
   4티어=키스톤(런의 방식이 바뀌는 것, 탭당 1~2개).
5. **모든 노드는 한 문장으로 왜 사는지 말할 수 있어야 한다.** 못 하면 뺀다.

## 3. 탭별 구성안

### 3.1 공용 — 운영 (17 → 16노드, 깊이 3, 뿌리 5)

출정 전후에 작용하는 것만. 전투 스칼라는 전부 연마로 이관.

| 뿌리 | 갈래 | 성격 |
|---|---|---|
| **엽전** | 엽전 눈(gold_gain) → 셈 밝은 눈(gold_gain) → **환전꾼**(키스톤, 신규) | 환전꾼 = 남는 재료를 엽전으로 자동 환전 |
| **기록** | 혜안(xp_gain) → 첫 발견(first_find) → 길눈(신규) | 길눈 = 출정 시작 시 지역 재료 1개 보장 |
| **행운** | 행운(luck) → 범의 눈(luck) | 드롭 |
| **준비** | 선수(start_level) → 네 번째 패(choice_count) | 런 시작 |
| **보험** | 긴 호흡(hit_invuln) → 회생(revive) → **두 번째 밤**(키스톤, 신규) | 두 번째 밤 = 패배해도 그 판 재화의 절반을 은행 |

**빠지는 것**: `sharp_talisman`(공격력), `quick_hands`(공속), `stone_skin`(피해감소),
`swift_charms`(투사체속도), `soul_pull`(자석), `tiger_eye`/`fang_grind`(치명) —
전부 연마에 같은 축이 있다. **7노드 제거.**

**신규 배선 필요**: 환전꾼, 길눈, 두 번째 밤.

### 3.2 연마 — 기본기 (27 → 24노드, 깊이 4, 뿌리 6)

순수 전투 스칼라의 유일한 집.

| 뿌리 | 사슬 |
|---|---|
| 힘 | 공격력 → 공격 속도 → 치명률 → 치명 피해 |
| 몸 | 체력 → 방비 → 피해 감소 → 숨 고르기(무적) |
| 걸음 | 이동 속도 → 자석 → 경험치 |
| 술 | 술력 → 범위 → 소신(화상 위력) |
| 불 | 화상 지속 → 화상 피해 |
| 시 | 탄속 → 탄수 |

**빠지는 것**: `refine_ward_radius`·`refine_area_radius`·`refine_orbit_count`·
`refine_chain_jumps`·`refine_seal_haste` (결계·선회·연쇄·봉인은 **우치 고유 축**이므로
우치로 이관), `refine_luck`·`refine_gold_gain`·`refine_first_find`(경제는 공용).
**8노드 이관/제거.**

### 3.3 우치 — 술법사 (15 → 14노드, 깊이 4, 뿌리 4)

*"부적 한 장이 몇 겹으로 도는가"*. 우치만의 규칙: 봉인·연쇄·결계·화상.

| 뿌리 | 사슬 | 키스톤 |
|---|---|---|
| 봉인 | 봉인 완화(seal_burst) → 봉인 속도(seal_haste) | **겹장**: 봉인이 터질 때 부적 1장을 되돌려준다 (신규) |
| 연쇄 | 연쇄 도약(chain_jumps) → 연쇄 수(chain_amount) | |
| 결계 | 결계 반경(ward_radius) → 법식 반경(area_radius) → 선회(orbit_count) | |
| 화염 | 오행 조화(area_scale) → 잿불(burn_dps) | **소신귀**: 화상으로 죽은 적이 주변을 태운다 (신규) |

**빠지는 것**: `talisman_zeal`(공속), `deep_sight`(치명률), `still_mind`(무적),
`spirit_arrows`(탄속), `spirit_harvest`(경험치), `iron_talisman`(피해감소) —
전부 연마/공용과 중복. **6노드 제거, 2 키스톤 신규.**

### 3.4 석주 — 무사 (10 → 12노드, 깊이 3, 뿌리 4)

*"버티면서 앞으로 나간다"*. 석주만의 규칙: 반격·기세·광역 근접.

| 뿌리 | 사슬 | 키스톤 |
|---|---|---|
| 반격 | 철벽(피격 시 반사, 신규) → 되받아치기(신규) | **되돌린 밤**: 체력 30% 아래에서 피해 +30% (신규) |
| 기세 | 연격(처치 시 공속 누적, 신규) → 기세 유지(신규) | |
| 무게 | 육중한 걸음(넉백, 신규) → 진각(광역, 기존 재사용) | |
| 뼈대 | 돌기둥(max_hp) → 무골(defense) | |

**빠지는 것**: `hwando_hone`·`grip_iron`(공격력 중복), `crush_step`(치명피해),
`slow_march`(이속), `unbending`(무적), `heavy_blood`·`iron_stance`(피해감소).
**7노드 제거, 6 신규.** 석주는 지금 "숫자만 있는 캐릭터"라 재설계 폭이 가장 크다.

### 3.5 월영 — 궁수 (10 → 12노드, 깊이 3, 뿌리 4)

*"한 발이 여러 겹을 뚫는다"*. 월영만의 규칙: 관통·거리·조준.

| 뿌리 | 사슬 | 키스톤 |
|---|---|---|
| 관통 | 관통(기존) → 갈래 시위(projectile_count) | **꿰뚫는 달**: 관통할수록 피해 증가 (신규) |
| 거리 | 원격(먼 적일수록 피해 +, 신규) → 바람 읽기(신규) | |
| 조준 | 형안(crit_chance) → 급소(crit_damage) | |
| 발놀림 | 가벼운 발(hit_invuln) → 그림자 걸음(회피, 신규) | |

**빠지는 것**: `rapid_nock`(공속), `far_scent`(자석), `fortune_wind`(행운),
`wind_read`(이속). **4노드 제거, 5 신규.**

| 탭 | 현재 | 안 | 제거 | 신규 |
|---|---:|---:|---:|---:|

케이던스 목표도 유지: 1판 12딩 · 최대 가뭄 ≤5판 · 만렙 ~130판.

## 6. 진행 순서 (각 단계 = 1커밋 + QA 게이트)

1. **정리 패스**: 중복 32노드 제거/이관, 탭별 배선 재구성. 신규 배선 없음 —
   기존 스탯만으로 5탭이 서로 다른 질문에 답하게 만든다. (데이터 + 캡 재산출 + 마이그레이션)
2. **공용 3종**: 환전꾼 · 길눈 · 두 번째 밤.
3. **월영 5종**: 관통 키스톤 · 원격 · 그림자 걸음.
4. **석주 6종**: 반사 · 기세 · 넉백.
5. **우치 2 키스톤**: 겹장 · 소신귀.
6. **밸런스 패스**: 케이던스·캡 재측정, `data/BALANCE.md` 갱신.

## 7. 기존 세이브 처리

제거된 노드는 `MetaTree.sanitize_state`가 이미 조용히 떨군다(N7-2 정책: 리워크는 가격
재조정이지 롤백이 아니므로 **환불 없음**). 이번엔 규모가 커서(32노드) 예외를 제안한다:
**제거 노드에 쓴 엽전 전액 환급** + 본거지 알림 한 줄. 구현은 1회성 마이그레이션 훅.
