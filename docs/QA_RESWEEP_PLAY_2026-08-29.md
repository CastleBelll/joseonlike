## 심각도 상

### R1 — 액티브 버튼 쿨다운 스윕이 전혀 움직이지 않는다 (원인 확정)
- 재현: 액티브 2개를 탭한 뒤 남은 쿨다운 7.6s / 6.0s / 4.0s / 1.0s 시점 캡처.
  `P_18_actives_cooldown_0/2/4/7.png`.
- 계측: 버튼 안쪽 40x40 픽셀 비교 — 네 프레임이 **사실상 동일**(변화 픽셀 94~114개,
  전부 버튼 밖 전장 픽셀). `_crops/active_disc_series.png` 참조.
  즉 남은 시간 1초와 40초를 화면에서 구분할 수 없다.
- 원인: `scripts/ui/combat_hud.gd:1697` `ActiveButton.set_cooldown()`
  ```gdscript
  var moved: bool = absf(fraction - _fraction) > 0.01
  _fraction = fraction
  if ready_flip or moved: queue_redraw()
  ```
  프레임당 fraction 변화는 축지(8초 쿨)가 `(1/60)/8 = 0.0021`, 벽사진(45초)이 `0.00037`
  로 **항상 0.01 미만** → `queue_redraw()` 가 한 번도 호출되지 않는다. `_draw()` 의
  `draw_arc(... TAU * _fraction ...)` 스윕 코드는 맞게 짜여 있으나 첫 프레임(≈1.0)에서
  얼어붙는다. 준비 완료로 돌아올 때만 다시 그린다.
- 영향: 쿨다운 "스윕"이라는 기능이 실전에서 존재하지 않는다. 브리핑의 확인 항목 실패.
