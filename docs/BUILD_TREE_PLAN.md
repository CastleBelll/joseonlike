# 빌드 트리 개편 계획 (N11-20)

오너 지시 (2026-08-31): *"노드별 늘어나는 %가 너무 많은 것 같고 각각 빌드가 나뉘었으면
좋겠어. 도사의 경우 화염 빌드, 번개 빌드, 저주 빌드, 봉인 빌드 등등. 지금 스킬들을
수정해야 할 것 같긴 해. 무사의 경우도 환도 빌드, 언월도 빌드 등등. 제대로 빌드를 나누고
업그레이드가 가능하게 하고, 액티브를 지금 캐릭터별로 너무 많이 해놨는데 기본 무기로
시작해서 빌드를 업그레이드해 나가는 느낌으로 갈 수 있을까?"*

**답: 갈 수 있다.** 무기 데이터는 이미 빌드 계열로 갈라져 있고(36종), 트리만 그것을
쓰지 않고 전역 %를 팔고 있었을 뿐이다.

---

## 1. 이미 있는 것 (측정)

무기 36종은 이미 **계열 + 진화**로 조직돼 있다.

| 캐릭터 | 빌드 계열 | 기본 → 진화 |
|---|---|---|
| 우치 | **화염** | 화부 → 화령부 · 화염 부적 · 화령 혼불 · 화염 결계 |
| | **번개** | 뇌부 → 뇌정부 · 뇌정 신장 |
| | **저주** | 살 → 귀살 |
| | **봉인** | 진언 → 봉인 진언 · 법검 → 봉마검 |
| | **결계/혼불** | 결계 → 화염 결계 · 혼불 → 화령 혼불 |
| 기룡 | **환도** | 환도 → 예리한 환도 · 귀철도 · 화염도 · 쌍환도 |
| | **언월도** | 월도 → 청룡언월도 |
| | **편곤** | 편곤 → 마상편곤 |
| | **검륜** | 검륜 (선회) |
| 초희 | **각궁** | 각궁 → 신궁 |
| | **쇠뇌** | 쇠뇌 → 수노기 (관통) |
| | **편전** | 편전 → 육량전 (직사) |

지금 트리가 파는 것: `burn_duration +15%`, `chain_jumps +1` 같은 **계열 스탯을 전역으로**.
즉 화염 빌드를 하든 말든 화상 노드를 사고, 사놓고도 화염 무기를 못 뽑으면 죽은 값이 된다.

액티브는 캐릭터당 2개가 **처음부터 전부** 주어진다 (축지+벽사진 / 철벽+참격 / 철질려+일제사).
빌드를 고르기도 전에 캐릭터의 전부가 열려 있어서 성장할 여지가 없다.

---

## 2. 바꾸는 것

### 2.1 캐릭터 탭 = 빌드 탭

캐릭터 탭의 노드를 전역 %에서 **빌드 단위**로 바꾼다. 한 빌드 = 한 가지, 가지마다 세 층:

| 층 | 하는 일 | 예 (우치 화염) |
|---|---|---|
| **뿌리 — 개방** | 그 계열 무기가 레벨업 풀에 등장하기 시작한다 | 「불을 다루는 법」 → 화부·화염 부적이 카드로 나온다 |
| **중간 — 심화** | 그 계열에만 걸리는 수치 (2~3개) | 화상 지속 · 화상 피해 · 폭발 반경 |
| **끝 — 키스톤** | 규칙이 바뀐다 / 그 빌드의 액티브가 열린다 | 「소신귀」: 화상으로 죽은 적이 주변을 태운다 |

**핵심 변화**: 뿌리를 안 사면 그 계열 무기가 **런에 아예 안 나온다**. 그래서 "기본 무기로
시작해서 빌드를 열어간다"가 성립한다. 지금은 캐릭터 카테고리만 맞으면 전부 나와서,
트리가 런을 바꾸지 못한다.

### 2.2 % 노드 다이어트

- 캐릭터 탭에서 전역 % 노드 **전부 제거** (우치 17 · 기룡 12 · 초희 14 중 약 30개).
- 남는 %는 **빌드 전용**만: 화상은 화염 가지 안에서만, 연쇄는 번개 가지 안에서만.
- 전역 %는 **연마 탭 9노드**로 끝 (공격력 · 공속 · 이속) — "누구나 사는 기본기".
- 공용 탭은 운영(경제 · 준비 · 보험) 그대로.

결과: 트리에서 "+x%" 카드가 절반 이하로 줄고, 나머지는 **무엇을 여느냐**가 된다.

### 2.3 액티브 = 빌드의 보상

캐릭터당 2개를 처음부터 주지 않는다.

| 캐릭터 | 기본(항상) | 빌드 키스톤이 여는 것 |
|---|---|---|
| 우치 | 축지 (이동) | 벽사진 ← 봉인 빌드 키스톤 |
| 기룡 | 철벽 (방어) | 참격 ← 언월도 빌드 키스톤 |
| 초희 | 철질려 (설치) | 일제사 ← 각궁 빌드 키스톤 |

기본 하나는 캐릭터의 손발이라 유지하고, 두 번째는 빌드를 끝까지 민 사람의 것이 된다.
다른 빌드를 밀면 다른 액티브가 열리는 구조라 다음 빌드를 열 이유가 생긴다.

### 2.4 스킬(무기) 수정 — 오너가 짚은 부분

빌드가 성립하려면 계열마다 **정체성이 달라야** 한다. 지금 겹치는 것들:

| 계열 | 지금 | 고칠 방향 |
|---|---|---|
| 화염 | 화부(폭발) · 화령 혼불(선회) · 화염 결계(장판) — 전부 "불" | 화상 중첩을 공유 자원으로: 쌓이면 터진다 |
| 번개 | 뇌부(연쇄) · 뇌정 신장(소환) | 연쇄가 튈 때마다 피해 **증가** (지금은 감소) |
| 저주 | 살 · 귀살 둘뿐 | 저주 = 지속 약화(받는 피해 증가) + 사망 시 전파 |
| 봉인 | 진언(충격파) · 법검(관통) | 봉인 스택이 터질 때 광역 — 구조 유지, 축적을 빌드 노드로 |

저주에는 지금 배선된 스탯이 **하나도 없다**. `curse_power`(약화 폭)와
`curse_spread`(사망 시 전파)를 새로 배선해야 빌드가 성립한다.

## 3. 규모와 순서

| 단계 | 내용 | 새 배선 |
|---|---|---|
| 1 | **무기 풀 게이팅**: 빌드 뿌리를 사야 그 계열이 런에 등장 | `LevelUp.candidates`에 해금 집합 인자 |
| 2 | **우치 4빌드**(화염 · 번개 · 저주 · 봉인) 재작성 + 저주 스탯 2종 | 중 |
| 3 | **기룡 3빌드**(환도 · 언월도 · 편곤) + 근접 스탯(넉백 · 기세) | 중 |
| 4 | **초희 3빌드**(각궁 · 쇠뇌 · 편전) — 기존 3기믹을 빌드로 재배치 | 소 |
| 5 | **액티브 해금**: 두 번째 액티브를 키스톤에 묶기 | 소 |
| 6 | 밸런스 패스 — 빌드별 승률 · 클리어 시각 측정 | — |

노드 수: 캐릭터당 빌드 3~4개 × (뿌리 1 + 심화 2~3 + 키스톤 1) = **12~16노드**.
셋 합쳐 40~48 + 공용 18 + 연마 9 = **67~75**. 지금(72)과 비슷하되 내용이 전부 바뀐다.

## 4. 위험한 지점

1. **빌드를 안 산 신규 플레이어**가 뽑을 무기가 없어진다 → 캐릭터마다 **기본 계열 하나는
   처음부터 열려 있다** (우치=부적/봉인, 기룡=환도, 초희=각궁). 트리는 *두 번째 빌드부터* 판다.
2. **기존 세이브**: 캐릭터 탭이 통째로 바뀌므로 N11-18과 같은 전액 환급을 다시 태운다.
3. **밸런스**: 빌드를 좁히면 한 계열만 파는 런이 생긴다. 계열별 dps를 `--batch`로 재고,
   빌드 간 편차가 2배를 넘으면 조정한다.

## 5. 오너 결정 (2026-08-31 확정)

1. **풀 게이팅** — 소프트. 안 산 계열도 나오되 산 계열이 4배 가중. (1단계 구현 완료)
2. **시작 빌드** — 플레이어가 **골라서 시작**한다. 출정 설정에 빌드 다이얼을 붙인다(예정).
3. **액티브** — **2개 그대로 유지**하고 수련이 둘 다 키운다 (주문 속도·깊은 수행).
   오너 정정(N11-20b): "한 개만 쓰고 업그레이드"는 액티브가 아니라 **무기** 얘기였다.
   그래서 계열 전용 영구 강화(벼리기/손속)를 배선했다.

## 6. 옛 질문 (해소됨)

1. **무기 풀 게이팅** — "안 산 빌드는 런에 안 나온다" vs "나오되 확률이 낮다".
   (전자 추천 — 트리가 런을 실제로 바꾼다)
2. **기본 개방 계열** — 우치=봉인/부적, 기룡=환도, 초희=각궁으로 시작해도 되는지.
3. **액티브 2번째를 키스톤에 묶는 것** — 지금 2개를 다 쓰던 사람에게는 하향이다. 진행할지.
