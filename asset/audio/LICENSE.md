# Audio provenance and licence

All audio in this directory was synthesized specifically for JOSEONLIKE by
`tools/asset/synthesize_audio.py`. It contains no samples, recordings, model
outputs, or third-party source material. The project may use, modify, ship, and
redistribute these files without attribution or additional licence obligations.

The configured Higgsfield audio endpoint was not used because it supports speech
only and explicitly rejects ambience, music, and sound-effect generation.
