# UI 크롬 — 오너 키트

오너가 인터페이스 전체를 한 장에 그렸다: `chrome 모음.png` (1536×1024).
`python asset/ui/slice_chrome_kit.py`가 조각의 **자기 투명도**로 70장을 잘라
`build/`에 이름을 붙여 낸다. 격자를 가정하지 않는 이유는 키트가 눈대중으로
배치돼 있고, 이 프로젝트에서 생성기 격자를 추측한 시도는 매번 피사체를 갈랐기
때문이다.

**`chrome 모음.png`는 오너 드롭이다. 어떤 도구도 여기에 쓰지 않는다.**
산출물은 전부 `build/` 아래로 간다.

---

## 코드가 읽는 방법

`scripts/ui/ui_icons.gd`:

- `kit_texture(piece)` — `build/<piece>.png`를 잘라내 **2배 축소**해서 준다.
  없으면 `null`이라 호출부는 쓰던 폴백을 그대로 유지한다.
- `kit_panel(piece, margin)` — 9-slice 스타일박스.
- `slot_panel(tint)` — 슬롯 프레임에 색조를 입힌 것.

**축소 2배는 취향이 아니다.** 원본 크기로 쓰면 테두리가 한 변 46px(구 크롬은
24px)이라 프레임이 내용 영역을 44px씩 먹는다. 실제로 레벨업 패널이 540 세로에
안 들어갔고 여섯 화면에 스크롤이 생겼다. 지금 값은 레이아웃이 만들어진 무게다.

## 조각 목록과 붙은 자리

### 붙어 있는 것

| 조각 | 쓰이는 곳 |
|---|---|
| `paper_panel` | `UiIcons.paper_panel()` — 일시정지·레벨업·결과·설정 네 화면 |
| `plate_brown` | `UiIcons.wood_button()` — 공용 버튼 3상태(색조로 구분) |
| `slot_0` | 무기·패시브 슬롯. 무기는 **등급 색으로 변조**해서 기존 신호를 유지 |

### 아직 안 붙은 것 — 붙일 자리 후보

| 조각 | 개수 | 후보 자리 |
|---|---|---|
| `scroll` · `title_plaque` | 2 | 타이틀 화면, 괴이록 상세 |
| `plaque_*` (크림·갈색·보라·남색·적색·금화·상자·트로피) | 9 | 섹션 제목, 결과 화면 행 |
| `tassel_*` | 4 | 술 달린 명패 — 강조 제목 |
| `plate_*` (크림·갈색·보라·적색) | 4 | 버튼 변형(위험·확인 등) |
| `btn_*` (메뉴·목록·격자·홈·좌·우·닫기) | 7 | 화면 전환, 팝업 닫기 |
| `icon_*` (?·i·톱니·소리·음악·트로피·편지) | 7 | 설정 항목, 도움말 |
| `checkbox_off/on` · `toggle_off/on/on_purple` | 5 | 설정 화면 |
| `bar_hp/timer/level` + `_cap`/`_fill` · `bar_track` | 9 | **지금 HUD 바에는 못 쓴다** — 아래 참고 |
| `slot_1..7` | 7 | 슬롯 색 변형 |
| `stat_strip` | 1 | 결과 화면 통계 띠 |
| `disc_0..8` | 9 | 술법 버튼, 원형 아이콘 배경 |
| `banner_*` (보라·청색·적색) | 3 | 결과 헤더, 보스 등장 배너 |

### HUD 바를 쓰지 않은 이유

키트 바는 한 변 62px에 금장 레일과 육각 아이콘 캡이 붙은 그림이다. 지금 HUD의
경험치 바는 **8px**, 체력 바는 **5px**, 보스 바는 6px다. 그 높이로 줄이면 장식이
뭉개져 지금의 단색 막대보다 나빠진다. 바를 쓰려면 **HUD 밴드 높이를 먼저 키워야
하고**, 그건 레이아웃 변경이라 별도 피처다(오너 지시: 가로·세로 배치를 건드릴
때는 제대로).

캡·채움·레일은 이미 잘라놨다(`bar_*_cap`, `bar_*_fill`, `bar_track`) — 밴드를
키우기로 하면 그날 바로 붙는다.

## 새 조각이 들어오면

키트를 다시 그리면 조각 수가 바뀐다. 슬라이서는 찾은 개수와 이름표 개수가
다르면 **아무것도 쓰지 않고 멈춘다** — 이름이 한 칸씩 밀려 엉뚱한 그림이
`paper_panel.png`로 저장되는 것이 조용히 벌어지는 것보다 낫다. 그때는 번호를
붙인 대조표를 다시 만들어 `NAMES`를 맞춘다.

## 확인

```sh
python asset/ui/slice_chrome_kit.py --dry-run                    # 조각 수와 이름만
godot --headless --path . res://tools/layout_sweep.tscn          # 12화면 × 11기기 × 2언어
godot --path . --resolution 540x960 res://tools/pause_check.tscn  # 세로
godot --path . --resolution 960x540 res://tools/pause_check.tscn  # 가로
```

크롬을 건드리면 `layout_sweep`을 반드시 돌린다. 테두리 두께가 바뀌면 내용
영역이 같이 바뀌고, 그 결과는 특정 해상도에서만 스크롤로 나타난다.
